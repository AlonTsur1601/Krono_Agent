## Version 0.2.0

- Grouped the desktop, arcade, runtime, and plugin work into the Windows x64 offline installer for 0.2.0.
- The focused Windows runtime smoke exercised the final browser navigation guard, last-tab closure, agent browser and terminal split, and tray execution. Focused Windows plugin and arcade runs exercised the bundled Node tool path and the Snake and Flap start/replay paths.
- The broad local Windows run exercised initial interactions in all 24 games, including Minesweeper right-click, Odd Color round 21, and Jigsaw drag. Passive Reversi and Sudoku tiles now retain accessible names without exposing an invoke action. The smoke fixture explicitly opens a manual PowerShell tab when the agent tab already exists.
- Native sync and scheduling checks covered a scheduled prompt appended to an existing conversation, inherited run settings, and rejection of an unapproved permissions increase. Live provider and extended gameplay checks remain listed above.
