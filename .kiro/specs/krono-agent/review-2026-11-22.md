# November 22 native feedback

| Area | Implementation and verification |
| --- | --- |
| Browser | Restored a continent glyph and compact toolbar hover treatment. Added a width-aware bookmark strip and a centered history tab with per-visit local time. Search shows loading in browser chrome and a stationary new-tab progress indicator. |
| Browser reliability | The Windows minidump from the installed 0.2.2 app points to a native WebView2 COM release on the managed finalizer thread. Browser lifecycle changes aim to reduce transient COM projections and ensure controls are initialized and closed predictably. Long-running sessions remain a separate acceptance check. |
| Native UI | Instructions use a viewport-height editor. Free-form Markdown fields can switch between source and preview. The compositor drives tab and menu motion. Typography is applied consistently to line labels and code surfaces. A fresh terminal opens after closing the last tab. |
| Models | A single selection control applies choice immediately. First detected model is the fallback, with manual selection stored per provider and retained through refresh. Local discovery omits endpoint and credential fields. Reasoning appears beside the composer, and Fast mode remains capability-gated. |
| Games and tray | Games build previews lazily and only save after gameplay changes. Reactivating the desktop shortcut restores the running window and its active workspace. |
| Account and releases | Updated the 0.2.2 migration note to direct older installations to the in-place installer. The hosted Supabase account service still reports Google sign-in disabled. Production requires the Krono Google OAuth client and approved redirects. |
| Plugins | Two-column catalog with 30 entries, per-plugin installation and removal, seven account integrations, and on-device skill packs. GitHub, Vercel, Notion, Linear, monday.com, and Netlify reached the live authorization step. Provider approval remains unverified. Firebase needs Google Cloud CLI. Hugging Face Hub was exercised as a public read-only integration. |
