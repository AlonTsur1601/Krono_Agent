## Continued native R7 and session lifecycle

Added a resizable native side panel with its own worker and model run, account-
local temporary-chat selector, parent link, transcript/message-point branching,
and frozen project instructions/memories. Chat-only tool omission is explicit in
both UI and system context. A branch cannot gain tools beyond its parent, and
it cannot propose/update memories. Reopening resumes the latest live branch;
message Branch creates a new snapshot. Panel width is stored per account.

Accepted user/completed assistant messages reset expiry to 24h; stream deltas,
tool events and transfers do not. Expiry cancels the active request, closes and
clears any open transfer preview, deletes temporary messages/metadata/chat,
and denies further sends. Launch/session restore purges expired rows. Kept
branches remove their expiry and become normal chats. Previewed/edited latest
replies are appended as new parent context, with a durable transactional queue
when the parent is running. Parent messages are never rewritten.
