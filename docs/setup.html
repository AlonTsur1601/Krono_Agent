Setup guide

Install Krono Agent on Windows, connect a model, and start your first chat.

Install and sign in

  1. Run the Windows x64 installer. Choose an installation folder and, if you want one, add a desktop shortcut.
  2. Open Krono Agent from the Start menu. Sign in or create an account.
  3. If you’re registering, open the confirmation email and follow its link. Keep Krono open on the confirmation screen so it can finish signing you in.

Connect a model

  1. Open Settings → Models → Provider.
  2. Local. Choose Local Model to discover models in Ollama, LM Studio, or Jan. Download a model first. In LM Studio or Jan, start the local server. For a custom endpoint, use the matching provider profile and enter the address including /v1.
  3. Cloud. Choose your provider, save its key in Krono, then select Test connection and load the available models.
  4. Select a model and click Use model. For a compatible endpoint, enable tool calling if the model supports it.

Start a conversation

  1. Open Chats, select New chat, and send a message in Chat mode.
  2. To work with files, create a project, add its folder, and choose it for the conversation. Select Agent and use Ask if you want to review file changes and commands before they run.
  3. Use Workspace beside the conversation to open the browser, terminal, or files.

Build from source

Install Node.js 24 or later and the .NET 10 SDK. Open PowerShell in the repository folder and run these commands.

npm ci
npm run dev

npm run package:win creates the Windows x64 app under release/Krono-Agent. Keep that folder together and launch KronoAgent.exe. The browser workspace uses WebView2 Evergreen Runtime.
