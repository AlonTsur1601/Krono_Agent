Krono Agent

A native Windows agent workspace with games to play while tasks run.

The application is being implemented and reviewed. There is no verified production installer available yet. Windows is the primary target; the interface uses WinUI 3, and macOS/Linux desktop interfaces are not implemented.

Development checks include account-ownership policy tests and an integrated PowerShell terminal and isolated WebView2 browsing. The WinUI interface includes local project and memory management, native Markdown and sixteen games, including Reversi, Sudoku, Stack and Color Gauntlet. Ollama, LM Studio and custom OpenAI-compatible servers can be configured; local model downloads and inference hardware acceptance are not bundled or verified yet. Full release acceptance is still pending.

Temporary side conversations keep a context snapshot, run independently in Chat mode, expire after 24 hours of message inactivity, and can be kept or transferred back to their parent at a safe boundary. They are stored locally; cross-device synchronization and attachments remain in development.

Provider setup includes OpenAI, Anthropic, Google, Azure OpenAI, xAI, Groq, Mistral and OpenRouter. Compatible endpoints use opt-in tool support per model. Credentials and real provider quotas are supplied by the user's account; fixture checks do not establish live provider acceptance.

Agent commands support detailed Ask approval, bounded PowerShell execution and cancellation. A native activity strip keeps task progress visible while playing and pauses the game when returning to the response. All sixteen games have local account-scoped saves, paused restoration and window-blur pause. Cloud save synchronization and durable background jobs remain in development.
