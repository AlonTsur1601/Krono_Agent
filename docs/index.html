Krono Agent

A native Windows agent workspace with games to play while tasks run.

Download for Windows (x64)

The installer lets you choose an installation folder and add a desktop shortcut. Krono Agent is in development and uses WinUI 3.

Development checks include account-ownership policy tests and an integrated PowerShell terminal and isolated WebView2 browsing. The WinUI interface includes local project and memory management, native Markdown and 24 games with actual gameplay previews, personal bests, favorites, search and category filters. Ollama, LM Studio and custom OpenAI-compatible servers can be configured; local model downloads and inference hardware acceptance are not bundled or verified yet. Full release acceptance is still pending.

Temporary side conversations keep a context snapshot, run independently in Chat mode, expire after 24 hours of message inactivity, and can be kept or transferred back to their parent at a safe boundary. They are stored locally; cross-device synchronization and attachments remain in development.

Provider setup includes OpenAI, Anthropic, Google, Azure OpenAI, xAI, Groq, Mistral and OpenRouter. Compatible endpoints use opt-in tool support per model. Credentials and real provider quotas are supplied by the user's account; fixture checks do not establish live provider acceptance.

Agent commands support detailed Ask approval, bounded PowerShell execution and cancellation. A native activity strip keeps task progress visible while playing and pauses the game when returning to the response. All 24 games have local account-scoped saves. Select a game to start fresh or continue an existing save; games pause when returning to chat or losing window focus. Optional account sync covers regular conversations, projects, memories, appearance and game data. Device keys, paths, tool permissions and temporary side chats remain local. Two-device fixtures verify offline retry and conflict resolution; production account acceptance and attachment sync are pending.

Opt-in one-time and recurring tasks run while the Windows app is open. Their results are kept in run history. The composer can send bounded text and code snapshots without their local paths.
