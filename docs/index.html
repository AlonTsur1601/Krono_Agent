Krono Agent

A native Windows agent workspace with games to play while tasks run.

The application is being implemented and reviewed. There is no verified production installer available yet. Windows is the primary target; the interface uses WinUI 3, and macOS/Linux desktop interfaces are not implemented.

Development checks include account-ownership policy tests and an integrated PowerShell terminal and isolated WebView2 browsing. The WinUI interface includes local project and memory management, native Markdown and twelve games. Ollama, LM Studio and custom OpenAI-compatible servers can be configured; local model downloads and inference hardware acceptance are not bundled or verified yet. Full release acceptance is still pending.
